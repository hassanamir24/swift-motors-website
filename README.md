# Swift Motors Website 🚗  

A modern and elegant automobile website inspired by the Mercedes-Benz aesthetic — built using **HTML5** and **CSS3**.  
This project was created as part of an **ICT course** to demonstrate web design skills and creativity.

---

## 🧩 Features  
- Sleek, luxury-inspired user interface  
- Responsive layout for different screen sizes  
- Sections for showcasing car models, company info, and promotions  
- Smooth hover animations and transitions  
- Hero section inspired by the official Mercedes-Benz promotional theme  

---

## 🛠️ Technologies Used  
- **HTML5**  
- **CSS3**  
- **Font Awesome** (for icons, if used)  
- **Google Fonts** (for typography, if used)
